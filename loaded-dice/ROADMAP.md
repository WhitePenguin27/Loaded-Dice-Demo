# LOADED DICE — 웹 버전 개발 로드맵

> 기획서 3종(초안 기획서 / 시스템 기획서 / UI·UI연출 기획서)을 기반으로,
> 웹(브라우저)에서 실행 가능한 형태로 개발한다.

## 기술 결정 사항

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 플랫폼 | 순수 웹 (HTML + CSS + JS, ES Modules) | 빌드 도구 없이 GitHub Pages/Firebase에 바로 배포 가능 |
| 3D/물리 | Three.js + cannon-es (CDN) | 주사위를 **실제 물리로 굴리고** 멈춘 뒤 윗면을 판정 |
| 난수 | **시드 없음 — 물리 결과 기반** | 요구사항 3. 주사위 눈은 물리 시뮬레이션 결과로 결정 |
| 데이터베이스 | JS 데이터 모듈 (`js/data/db.js`) | 요구사항 4. 족보/주사위/월드룰/로컬룰/와일드페이스/리드미노/스테이지 테이블 전부 코드화 |
| 이미지 | Python(Pillow) 픽셀아트 생성 스크립트 + 런타임 캔버스 텍스처 | 요구사항 1. 도트 그래픽(선술집/도박장 컨셉) |
| 세이브 | localStorage | 시스템 기획서의 세이브 시점(월드 룰 확정 시 / 점수 기입 시) 준수 |
| 폰트 | 카페24 PRO UP(제목) + Galmuri11(본문) | UI 기획서 폰트 가이드 그대로 |
| 호스팅 | GitHub Pages (정적 배포) | 요구사항 2 |

### '로디드(사기) 주사위'의 물리적 구현
기획서의 "[N] 눈금 등장확률 증가" 리드미노는 시드 조작 대신,
**주사위 강체의 무게중심을 해당 면 반대쪽으로 치우치게** 하여(내부 추 질량 추가)
실제 물리적으로 확률을 왜곡한다. → 게임 제목 그대로의 구현.

## 개발 순서 (Phase)

### Phase 0 — 프로젝트 셋업
- 폴더 구조, 로컬 개발 서버, import map(three/cannon-es CDN)

### Phase 1 — 데이터베이스 구축  ※ 요구사항 4
- 족보 21종 (기본 숫자 6 + 보너스 + 기본 조합 6 / 추가 숫자 4 + 추가 조합 10)
- 주사위 8종 (눈금 변형: 홀수/짝수/묵직한[0,0,4,4,8,8]/하이[2~7] 등, 눈금 최대 10)
- 월드 룰 8종 (게임 전체 적용 — 주사위 6개, 스코어 -50%, 시작 골드 등)
- 로컬 룰 10종 (스테이지 패널티 — 재굴림 1$, 목표 +50%, 주사위 봉인 등)
- 와일드페이스 12종 (발라트로 조커 포지션 — 족보 강화/배수/골드/패배 방지)
- 리드미노 10종 (폴리오미노 형태 주사위 강화 — 점수+/가중치/재굴림/골드)
- 스테이지 목표 점수 테이블, 로딩 팁 테이블

### Phase 2 — 코어 요트 엔진
- 물리 주사위: 굴리기 → 정지 감지 → 윗면 판정 → 눈금 확정
- 점수 계산 파이프라인: **기본 족보 → 월드/로컬 룰 → 와일드페이스 → 리드미노** (기획서 순서)
- 점수판(플레이스홀더 미리보기 포함), 등록 횟수/재굴림 횟수, 보너스 점수

### Phase 3 — 로그라이크 루프
- 메인 → 월드 룰 선택(캐러셀) → 로컬 룰 선택 → 플레이 → 보상 → 상점 → 다음 스테이지
- 보상 골드 공식: 로컬 룰 배정 골드 + ⌊log₂(스테이지)⌋ + 남은 등록횟수
- 패배(게임 아웃) / 10스테이지 클리어(승리)

### Phase 4 — 아이템 시스템
- 와일드페이스: 효과 엔진, 최대 5개(월드 룰로 +1), 교체 팝업, 중복 미등장
- 리드미노: 폴리오미노 배치 그리드(주사위별 상이), 강화(상점), 보관함
- 상점: 4슬롯(리드미노 50% / 와일드페이스 30% / 주사위 20%), 주사위 교체

### Phase 5 — 아트/연출  ※ 요구사항 1
- Pillow 픽셀아트 생성(배경/패널/아이콘), 주사위 면 텍스처(런타임 캔버스, 0~10 눈금)
- 카페24 PRO UP + Galmuri 웹폰트, WebAudio 효과음(굴림/클릭/승리)

### Phase 6 — 세이브/해금
- localStorage 세이브(기획서 세이브 시점 준수), 삭제 조건(패배/포기/새 게임)
- 해금 시스템: 월드 룰/아이템 해금 조건 + 해금 연출

### Phase 7 — QA & 배포  ※ 요구사항 2
- 브라우저 실플레이 테스트 → GitHub Pages 배포

## 1차 구현 범위 제외 (후속 과제)
- 다국어(한국어 고정), 상세 설정 팝업(그래픽/키보드), 컬렉션 도감 화면
- 로컬 룰 분기 지도 → 3지선다 카드 선택으로 간소화
- 7면체 등 비정육면체 주사위 → 눈금 변형 주사위로 대체 (물리 안정성)
- 모바일 터치 최적화
